## 🏥 تطبيق أقرب مشفى (Nearest Hospital)

تطبيق ويب ذكي ،رابط تنزيله يقع داخل منصة كوكب التمريض يتيح للمستخدمين **تحديد أقرب مشفى أو مركز صحي** من موقعهم الجغرافي الحالي بسرعة ودقة في حالات الطوارئ.

### أبرز مميزات تطبيق أقرب مشفى:
* **تحديد الموقع التلقائي (GPS):** العثور على أقرب مستشفى أو مستوصف طبي قريب منك بضغطة زر.
* **عرض المسافة والاتجاهات:** إظهار المسافة الدقيقة وأسرع طريق للوصول إلى قسم الطوارئ عبر الخرائط.
* **واجهة سريعة وخفيفة:** يعمل مباشرة من المتصفح دون الحاجة إلى تثبيت معقد.

**كلمات مفتاحية:** أقرب مشفى، أقرب مستشفى من موقعي، تحديد أقرب مستشفى، طوارئ، دليل المستشفيات، كوكب التمريض، Nearest Hospital، Nursing Planet.
